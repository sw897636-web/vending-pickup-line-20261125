One pickup line a vending machine would use on a passing human — an entry for the [make.fun](https://make.fun) competition ["One Line, One Minute: The Vending Machine Pickup Line Contest"](https://make.fun/c/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee).

## The line

> Press B7 and I'll drop my finest chips, keep the change, and throw in my number — which is just this machine, stuck on you like the crisps in my coils.

151 characters, one line, first person, machine voice: B7, finest chips, exact change, the machine's own number, and the crisps stuck in its coils.

## Run

Requires Node.js 22.18+ (Node runs the TypeScript directly):

```sh
node main.ts
```

Writes the line to `/output/entry.txt`.
